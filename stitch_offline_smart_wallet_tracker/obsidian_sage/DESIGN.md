## Brand & Style

This design system is engineered for prolonged financial focus, operational serenity, and reduced sensory strain. Designed for individuals and professionals navigating complex portfolios, high-volume transactional flows, and wealth planning, it substitutes high-alert urgency with quiet composure.

The visual direction marries understated minimalism with technical ergonomics:
- **Calm Authority:** Eliminates neon glows, high-frequency motion, and high-contrast tension in favor of grounded, stable value representation.
- **Ergonomic Rest:** Employs warm obsidian slate foundations that alleviate eye fatigue during extended screen sessions.
- **Organic Assurance:** Uses muted sage-mint botanicals as positive confirmations and yield states, signaling sustainable growth rather than volatile speculation.

## Colors

The palette operates on a disciplined luminance gradient designed to avoid chromatic vibration and harsh contrasts.

### Foundational Surfaces
- **Canvas Base (`#0D1117`):** The grounding deep slate backdrop. Used for full-viewport canvas and sub-navigation wells.
- **Surface Layer 1 (`#161B22`):** Primary card, panel, and table containers.
- **Surface Layer 2 (`#21262D`):** Interactive inputs, nested rows, hover targets, and elevated overlays.
- **Structural Boundary (`#30363D`):** Hairline borders, dividers, and structural outlines providing tactile separation without visual noise.

### Functional Accents
- **Primary / Growth (`#2EA043`, hover/highlight `#3FB950`):** An organic sage-mint. Denotes positive metrics, completed transactions, key action items, and portfolio upward mobility.
- **Secondary / Attention (`#D29922`):** A soft warm amber-gold. Reserved for pending settlement periods, yield obligations, warnings, and scheduled transfers.
- **Tertiary / Metadata (`#8B949E`):** Powdered slate for secondary captions, table column headers, and inactive timestamps.
- **High-Readability Foreground (`#F0F6FC`):** Pure balanced white. Reserved strictly for primary values, key balances, and prominent titles.
- **Muted Body (`#C9D1D9`):** Neutral reading tone for continuous prose and descriptive copy.

## Typography

Typography prioritizes tabular clarity and relaxed comprehension. 

- **Primary Typeface (`Manrope`):** Selected for its balanced geometric framework, open counters, and serene neutrality across headers and reading passages.
- **Numeric & Technical Typeface (`JetBrains Mono`):** Applied to currency amounts, percentage variances, transaction hashes, and asset tickers to guarantee vertical alignment, zero scanning friction, and monospace tabular stability.

### Rules of Usage
- **Numeric Data:** Always render balances, deltas, and units in `jetbrainsMono` with tabular figures enabled.
- **Header Restraint:** Avoid ultra-heavy weights (700+); cap structural weights at `600` to prevent visual bloat against deep slate backgrounds.
- **Metadata Labels:** Render section headers and card tags in `label-caps` using uppercase tracking to establish hierarchy without competing with primary data values.

## Layout & Spacing

The layout philosophy follows a rhythm of generous spatial buffers designed to lower cognitive load. Information density is managed through structural rhythm rather than spatial compression.

### Grid Architecture
- **Desktop (1024px+):** 12-column fluid grid bound to a maximum width of `88rem` (`1408px`), centered with `3rem` margins and `1.5rem` gutters.
- **Tablet (768px - 1023px):** 8-column layout with `2rem` margins and `1.25rem` gutters.
- **Mobile (320px - 767px):** 4-column layout with `1rem` margins and `1rem` gutters. Stacks asymmetric ledger and metrics views into single-column modules.

### Vertical Rhythm
- Component-interior padding scales predictably using `space-md` (`16px`) for compact tools and `space-xl` (`32px`) for primary dashboard cards.
- Complex analytics or ledger entries must maintain a minimum row height of `48px` to ensure clean touch targets and clear horizontal separation.

## Elevation & Depth

This system intentionally rejects heavy dropshadows, blurred multi-colored glows, and stark pure-black occlusions. Depth is rendered via **Tonal Surface Stacking** accented by calibrated hairline borders.

### Surface Tiers
1. **Base Layer (`#0D1117`):** The bottom canvas. Houses application navigation chrome, background gutters, and contextual page headers.
2. **Container Layer (`#161B22`):** Primary structural surface for content cards, data tables, and analytics modules. Elevated via a continuous hairline boundary of `1px solid #30363D`.
3. **Elevated Interactive Layer (`#21262D`):** Input fields, contextual dropdown menus, flyout filters, and table hover selections.
4. **Floating Modals & Sheets (`#161B22` with ambient diffusion):** For confirmations and key actions, combine `#161B22` with a subtle, non-distracting ambient shadow: `box-shadow: 0 16px 36px rgba(1, 4, 9, 0.45), 0 0 0 1px #30363D`.

### Optical Transitions
Hover and active states must shift surface tones rather than lifting elements on the z-axis. Avoid scale-up animations (`transform: scale(1.02)`) in data environments; prioritize subtle background luminescence transitions (`#161B22` to `#21262D` over `150ms ease`).

## Shapes

The design system uses a balanced `roundedness: 2` (base `0.5rem` / `8px`) geometry to establish an approachable, precise visual tone.

- **Base Corner Radius (`0.5rem` / `8px`):** Used for input fields, standard buttons, data tables, and interactive controls.
- **Large Corner Radius (`1rem` / `16px`):** Applied to primary metric cards, modal dialogs, and parent view containers.
- **Pill Radius (`9999px`):** Applied strictly to status tags, category chips, badge indicators, and sub-filter pills to create immediate visual contrast against geometric card structures.

## Components

### Buttons
- **Primary:** Background `#2EA043`, text `#FFFFFF`, radius `8px`, font `Manrope SemiBold 14px`. On hover, background shifts to `#3FB950`. No text-shadows or directional gradients.
- **Secondary / Subdued:** Background `#21262D`, text `#C9D1D9`, border `1px solid #30363D`. On hover, border transitions to `#8B949E` and text shifts to `#F0F6FC`.
- **Ghost:** Transparent background, text `#8B949E`, padding matching standard buttons. On hover, background `#21262D` and text `#F0F6FC`.

### Chips & Badges
- **Status Pills:** Compact height (`24px`), horizontal padding (`8px`), border-radius `9999px`. Text rendered in `label-data-sm`.
  - *Positive/Settled:* Background `rgba(46, 160, 67, 0.15)`, text `#3FB950`, border `1px solid rgba(46, 160, 67, 0.25)`.
  - *Pending/Obligation:* Background `rgba(210, 153, 34, 0.15)`, text `#D29922`, border `1px solid rgba(210, 153, 34, 0.25)`.
  - *Neutral/Idle:* Background `rgba(139, 148, 158, 0.15)`, text `#8B949E`, border `1px solid #30363D`.

### Input Fields
- Height `40px`, background `#0D1117`, border `1px solid #30363D`, radius `8px`.
- Text styled in `body-md` (`#F0F6FC`), with placeholder text in `#8B949E`.
- Focus ring: non-disruptive `1px solid #2EA043` paired with `box-shadow: 0 0 0 2px rgba(46, 160, 67, 0.2)`.

### Checkboxes & Radios
- Size `16px × 16px`, background `#0D1117`, border `1px solid #30363D`, radius `4px` (checkbox) or `9999px` (radio).
- Active state fills with `#2EA043`, border `#2EA043`, displaying an obsidian slate check/dot (`#0D1117`).

### Cards & Ledger Lists
- **Cards:** Background `#161B22`, border `1px solid #30363D`, radius `16px`, interior padding `24px`.
- **Ledger Rows:** Alternating hover state via `#21262D`. Dividers between rows use `1px solid #21262D` without full borders, keeping data scans quiet and frictionless.

### Financial Metric Displays
- Standard compound unit structure: Category title in `label-caps` (`#8B949E`), primary numeric volume in `display-lg` or `headline-xl` (`#F0F6FC`), and trend variance rendered in a status pill inline with the metric.
